# ДЗ "Банковские операции"

## Описание

ДЗ "Банковские операции" - это домашнее задание в рамках курса "Python-разработчик". 
В нем создается виджет для обслуживания банковских операций клиента. Данный проект 
содержит функции, которые маскируют номер карты и номер счета клиента, фильтруют список 
банковских операций, сортируют его по убыванию либо по возрастанию, либо по дате операций

## Установка

1. Клонируйте репозиторий:

   ```
   git clone git@github.com:Katerina-Nikolaeva/test_poetry.git
   ```

2. Установите зависимости:

   ```
   pip install -r requirements.txt
   ```
